# Security

Please report vulnerabilities **privately**. Do not open a public issue for secrets or exploits.

## How to report

1. Prefer GitHub **Security Advisories** on this repository (private report).
2. If the repo is not yet on GitHub, email the maintainer listed on the profile that published this demo.

## Please include

- Affected path / endpoint
- Reproduction without real user data
- Whether secrets appear to be exposed

## Please never

- Commit `.env`, API keys, tokens, or certificates
- Upload real user recordings or personal data
- Paste production `service_role` or SiliconFlow keys into issues

This public clone defaults to `DEMO_MODE=true` and must not require real credentials to run.
