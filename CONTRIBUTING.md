# Contributing

This repository is a **portfolio demo**, not an open production product.

## Do not submit

- API keys, tokens, passwords, certificates
- `.env` files with real values
- Real user recordings, names, emails, or device IDs
- Production Supabase URLs or service-role keys
- High-resolution unpublished design source files

## Welcome

- Honest fixes that keep DEMO_MODE working without secrets
- Documentation clarifications
- Accessibility and demo-stability improvements

Open a PR against the default branch. Keep diffs small.
